# Luh Gerald Eco System

A personal AI-powered business command center built across 6 departments.

## Departments

- **Marketing Suite** (`/marketing-suite`) — campaigns, growth, social strategy
- **Content Studio** (`/content-studio`) — content creation, scripts, drafts
- **Dev Bay** (`/dev-bay`) — tools, automations, scripts, technical builds
- **Operations Hub** (`/operations-hub`) — task tracking, workflows, SOPs
- **Finance Office** (`/finance-office`) — budgets, pricing, revenue tracking
- **Research Lab** (`/research-lab`) — market research, trends, experiments

## Frontend

The `frontend/` folder contains the Next.js app that ties all departments
together into one dashboard — see `frontend/README.md` for setup.
